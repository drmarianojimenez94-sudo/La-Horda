# Skins de los sets UNIVERSALES (cualquier campeón)

Son 11 sets que puede completar cualquiera de los 12 campeones. Una skin "de cuerpo" tiene que respetar la silueta de CADA campeón, así que cada set necesita **una hoja completa por campeón** (11 × 12 = 132 hojas). Hoy no existe ninguna.

**Recomendación de producción:** empezar por los sets de campeón (12 hojas, una por campeón). Para los universales, producir primero la combinación más usada (el set temático con el campeón que mejor lo aprovecha, marcado ★ abajo). Mientras no exista la hoja, el set completo muestra el aura plena (ya implementada): nunca se dibuja una skin a medias.

## Plantilla de prompt (una hoja por set × campeón)

Adjuntar el atlas canon del campeón y reemplazar los datos entre llaves. La lista de animaciones de cada campeón está en su ficha de set de campeón (misma lista).

```
Full sprite sheet (ALL animations) of the EXACT SAME character as the attached reference atlas ({campeón}, LA HORDA) — same body, proportions, height, face, weapon, camera — now wearing the complete "{set}" armor set: {piezas}. Set theme: {tema}. Accent color rgb({aura}). Animations, one row each, in the same order and frame counts as the reference atlas. Uniform grid, feet on the same baseline, side views facing right. dark-fantasy detailed 16-bit pixel art, same grammar as the LA HORDA roster (1px dark outline, 2-3 flat tones per color, limited palette, crisp alpha, no gradients/airbrush, no HD painting), transparent background, NO text, NO labels, NO frames, NO grid lines.
```
